It seems likely that you have a zero-length key with the given path as it's name at the location that is also a directory (i.e., there are keys with that name as a prefix). Some tools such as the GCS console create these when you choose to "create a directory", because GCS doesn't actually support directories. In such a case, I'm not sure what the correct result of `info` ought to be. 

(note that the "kind" field is not important, it's the "type" that matters)
