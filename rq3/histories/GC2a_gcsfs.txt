Issue: Doesn't work for a file path containing a hashtag (`#`)
The lib cannot read a file with the file path containing `#`. Weird thing is that it has no error too, just nothing is read. A silent bug.

```python
fs = gcsfs.GCSFileSystem()

# Nothing printed out
data = fs.open("gs://sample_project/my_folder/#this_is_file.json")
print(data.read())
data.close()

# Then I change the file name to remove `#`
# This works
data = fs.open("gs://sample_project/my_folder/this_is_file.json")
print(data.read())
data.close()
```

Not sure if there is an easy way to fix?
