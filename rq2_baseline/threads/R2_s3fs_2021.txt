Cache invalidation has unintended side effects
It seems that an invalidated cache starts caching any search, and that cache affects separate instances of `S3FileSystem`:

```python
Python 3.7.0 (v3.7.0:1bf9cc5093, Jun 27 2018, 04:59:51) [MSC v.1914 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>> import s3fs
>>> fs1 = s3fs.S3FileSystem()
>>> fs = s3fs.S3FileSystem()
>>> before = fs1.ls('s3://very-public-bucket-dask/')
>>> fs.invalidate_cache('s3://very-public-bucket-dask/alpha')
>>> fs.find('s3://very-public-bucket-dask/alpha')
['very-public-bucket-dask/alpha/']
>>> after = fs1.ls('s3://very-public-bucket-dask/')
>>> before
['very-public-bucket-dask/alpha', 'very-public-bucket-dask/beta', 'very-public-bucket-dask/gamma']
>>> after
['very-public-bucket-dask/alpha/']
>>> s3fs.__version__
'2021.06.0'
>>>
```

I would expect `before == after` - unless I'm missing something important.
