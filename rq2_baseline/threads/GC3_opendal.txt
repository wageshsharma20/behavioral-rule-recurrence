idea: Make List return the path itself
In [RFC 3243: List Prefix](  we make it clear that list won't return itself. 

However, this behavior does not align with either local file systems or AWS S3 services, which can confuse users. Furthermore, this behavior makes it impossible to list versions of a path expected to be supported at  

So I propose to change the current behavior to always return `path` itself if exists.
